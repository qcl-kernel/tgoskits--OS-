# 数据文件说明

`data/` 不是重复的构建产物，而是报告所引用的实验证据副本。

| 类型 | 用途 |
| --- | --- |
| `.log` | 串口或运行时日志。记录启动、协议压测、长稳请求以及故障恢复现场；`task2-direct/*.serial.log` 是受控串口会话中保留的摘要。 |
| `.json` | 机器可读的汇总、拓扑/协议清单、PASS 结果和证据 manifest。脚本从这些文件读取统计值，报告也用它们标明证据边界。 |
| `.csv` | StarryOS 周期 probe 的逐样本原始数据。四个 `starry_idle_5ms_30min_r*.csv` 各含约 360,000 个样本，用于重新计算 P99/P999、最大 jitter 和 missed。 |
| `sha256sums.csv` / `*.txt` | 文件完整性校验记录，不是新的实验数据。 |

因此文件数量多是因为每个实验场景和故障注入都单独留证，便于复核；大体积 guest 镜像和未选入报告的原始材料仍在 `transfer-to-vm/`，没有复制进本仓库。
