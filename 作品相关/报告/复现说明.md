# 复现说明

本目录只负责重建图表和阅读证据摘要，不启动 AxVisor、QEMU 或 Docker。查看图表时优先打开 `figures/*.png`，不要直接打开 `data/task1-csv/` 下的大型 CSV。原始大型镜像仍保留在 `/home/whiecloud/transfer-to-vm/task1-artifacts`，没有复制到本仓库。

## 生成图表

```bash
cd /home/whiecloud/作品相关
python3 scripts/build_figures.py
python3 scripts/build_overview.py
python3 scripts/svg_to_png.py
```

输出目录为 `figures/`。`build_overview.py` 生成三项任务整体链路总览。脚本使用短暂的 SVG 中间文件生成标准 RGB PNG，转换后自动删除 SVG。图表脚本使用 Python 标准库解析 JSON 和串口摘要，不依赖 matplotlib；PNG 导出脚本使用 CairoSVG，并在转换前检查 `Noto Sans CJK SC` 中文字体，避免生成黑框。

## 证据来源

任务一摘要来自 `data/task1-archive-summary.json`、`data/phase9-smp3-freeze.json` 和 `data/rtthread-baseline-summary.json`。四份周期 CSV 位于 `data/task1-csv/`。

任务二 direct 摘要来自 `data/task2-direct/`，拓扑和协议清单来自 `data/direct-topology-manifest.json`，可靠性结果来自各个 `*_PASS.json`。

## 解释边界

图表中的任务一数据是 StarryOS 用户态周期 wakeup jitter。它不能单独证明 IRQ latency，也不能替代严格 before/after。任务二吞吐和 RTT 只来自 direct TAP/bridge 记录。任务三没有实测模型数据，完成矩阵中的红色条明确表示缺少真实闭环证据。
